# AI_HISTORY

互動式 AI 模型歷史／族譜時間軸，整理 2023–2026 年主流 LLM、Reasoning、Multimodal、Coding、Agent 模型。

## 快速預覽

主頁入口：`index.html`

若啟用 GitHub Pages，建議：

- Branch: `main`
- Folder: `/ (root)`

Pages 網址預期為：

`https://janwiao.github.io/AI_HISTORY/`

## 操作

- 桌面：滑鼠左鍵拖曳、Ctrl/Cmd + 滾輪縮放
- 手機：單指拖曳、雙指縮放
- 上方可快速跳到不同品牌
- 模型節點可點擊來源

## 資料

`data/AI模型完整族譜_2023-2026_v2.xlsx`

包含模型／重要版本、發布日期、能力路線、開放型態、備註與來源。
