# 2026-11-26｜AI 歷史資料增補

- **MAGI-2（11/24）**：Sand.ai 的 480B 旗艦視聽模型，原廠宣告最高 30 秒、1080p、25 fps，可參考圖、影音並編輯影片。原廠文件列出須開通的組織 API，未實際呼叫付費端點；官方預告後續開放，不宣稱旗艦權重已可下載。[公告](https://sand.ai/blog/magi-2/)／[API](https://platform.sand.ai/docs/get-started/)
- **MAGI-2 Preview（8/5）**：補收 114B 研究版，採官方公告日。原廠模型卡列 Apache 2.0 與權重；不能把此版的存取或授權視為 480B 旗艦的狀態。[公告](https://sand.ai/blog/magi-2-preview/)／[模型卡](https://huggingface.co/sand-ai/MAGI-2-preview)
- **Ternary Bonsai 2.5 27B（11/24）**：PrismML 以 Qwen3.8-27B 為基礎，加強長程程式任務及多輪工具使用。原廠列模型大小約 5.9 GB，並公開 Apache 2.0 權重；執行時所需記憶體會依推論設定而變。GGUF、MLX 是同一節點。[公告](https://prismml.com/news/prismml-launches-ternary-bonsai-2-5-27b)／[模型卡](https://huggingface.co/prism-ml/Ternary-Bonsai-2.5-27B-GGUF)

共 328 個模型／版本節點、43 個品牌、9 張 Agent／工具卡。僅查核本批資料，未重驗全史。
