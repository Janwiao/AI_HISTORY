# 2026-11-20｜AI 歷史資料增補

補收 11/16 公告的 Sage-S2.1-Flash，以及 11/18 列入 OVHcloud 官方 API 目錄的 Olala mini、Translate 和 Summarize。共 293 個模型／版本節點、36 個品牌、9 張 Agent／工具卡。

- **Sage-S2.1-Flash**：上海人工智慧實驗室 11/16 公告發布的書生科學多模態模型；支援專業科研資料理解，接入端硯科學發現平台。官方模型卡以 MIT 提供程式與權重；FP8 為同模型量化版本，不另計節點。未確認通用託管 API。 [官方來源 1](https://www.shlab.org.cn/news/5444320)／[官方來源 2](https://huggingface.co/internlm/Sage-S2.1-Flash)
- **Olala-v1.0-mini-7A1B**：OVHcloud 11/17 預告，官方 AI Endpoints 目錄記載 11/18 上架；11/19 峰會正式亮相，官方 Hugging Face 模型卡亦以 11/19 為權重發布日。32K 上下文，混合 Mamba-3／注意力架構，Apache 2.0。GGUF 不另計模型。 [官方來源 1](https://corporate.ovhcloud.com/en-ie/newsroom/news/ovh-olala-mini/)／[官方來源 2](https://www.ovhcloud.com/en/public-cloud/ai-endpoints/catalog/olala-v1-0-mini-7a1b/)／[官方來源 3](https://huggingface.co/OVHaiLLM/Olala-v1.0-mini-7A1B)
- **Olala-v1.0-translate**：OVHcloud 官方 API 目錄記載 11/18 上架，8K 上下文；翻譯專用，需指定來源與目標語言。官方峰會稱開放權重，API 目錄標示 Apache 2.0；未獨立確認權重下載時間。 [官方來源 1](https://www.ovhcloud.com/en/public-cloud/ai-endpoints/catalog/olala-v1-0-translate/)／[官方來源 2](https://blog.ovhcloud.com/en/posts/ai-summit-2026-announcements/)
- **Olala-v1.0-summarize**：OVHcloud 官方 API 目錄記載 11/18 上架，62K 上下文，具結構化摘要與工具呼叫；峰會稱作 Summarise，為同一摘要支線。官方峰會稱開放權重，API 目錄標示 Apache 2.0；未獨立確認權重下載時間。 [官方來源 1](https://www.ovhcloud.com/en/public-cloud/ai-endpoints/catalog/olala-v1-0-summarize/)／[官方來源 2](https://blog.ovhcloud.com/en/posts/ai-summit-2026-announcements/)

Olala 峰會另列 Base 和 SFT；本批未獨立確認其可取得版本或 API 上架日期，暫不新增。Sage 科研平台與 OVHai Workspace 不計入模型數。保留歷史底稿和所有原有節點；本批未全量重驗。
