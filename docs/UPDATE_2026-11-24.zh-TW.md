# 2026-11-24｜AI 歷史資料增補

新增十三筆，合計 321 個模型／版本節點、41 個品牌、9 張 Agent／工具卡。

- **GLM-5.4（11/23）**：Z.ai 首款 Loop Transformer 旗艦。GLM Coding Plan、ZCode 與 Z.ai Chat 可使用；一般 API 與公開權重尚待推出。[原廠公告](https://z.ai/blog/glm-5.4)
- **LingSante-3.1-flash／air-VL（11/23）**：11/22 技術文，採 11/23 螞蟻集團對外公告。兩款 MIT 權重，一款文字、一款文字與圖片輸入；量化格式及 Afu 產品功能不再另計。[集團新聞稿](https://via.tt.se/pressmeddelande/4651683/ant-groups-ai-app-afu-open-sources-medical-and-health-ai-model-family?lang=en&publisherId=259167)／[flash](https://huggingface.co/inclusionAI/LingSante-3.1-flash)／[air-VL](https://huggingface.co/inclusionAI/LingSante-3.1-air-VL)
- **WePocketModel1.0-2B／4B（11/23）**：微信 AI 兩種不同規模的端側多模態權重，可產生文字、嵌入或結構化決策；Apache 2.0，GGUF 不另計。[原廠專案](https://github.com/Tencent/WePocketModel)／[2B 模型卡](https://huggingface.co/tencent/WePocketModel1.0-2B)／[4B 模型卡](https://huggingface.co/tencent/WePocketModel1.0-4B)
- **WeMM-Ecom（11/23）**：騰訊電商理解支線的 0.8B、2B、4B、9B、35B-A3B 五款權重。以實際 BF16 權重上傳日為準，不採 11/18 初始倉庫日期；FP8、GPTQ、GGUF 不另計。[0.8B 歷程](https://huggingface.co/tencent/WeMM-Ecom-0.8B/commits/main)／[2B](https://huggingface.co/tencent/WeMM-Ecom-2B/commits/main)／[4B](https://huggingface.co/tencent/WeMM-Ecom-4B/commits/main)／[9B](https://huggingface.co/tencent/WeMM-Ecom-9B/commits/main)／[35B-A3B](https://huggingface.co/tencent/WeMM-Ecom-35B-A3B/commits/main)
- **Sarvam-105B-1711（11/22）**：新 checkpoint，BF16 與 NVFP4 皆可下載；API 既有名稱不變、底層改用 1711。[原廠公告](https://www.sarvam.ai/blogs/sarvam-105b-1711)／[API 更新](https://docs.sarvam.ai/changelog/2026/11/22)
- **Ling-3.2-flash（11/5）與 Ming-3.0-tts-0.5B（10/19）**：按螞蟻百靈的 API 上線日補錄。Ming 可另下載 MIT 權重；不將 API 日期視為其權重首發，也不將 Ming 的授權套用到 Ling。[開發者更新日誌](https://developer.ant-ling.com/zh-CN/docs/getting-started/changelog/)／[Ming 模型卡](https://huggingface.co/inclusionAI/Ming-3.0-tts-0.5B)
- **GPT-6.2 Sol**：保留 11/17 發布日，補記 11/23 以 Sol 為基礎的對話調校版開始向指定方案的 Chat 分頁分批推出；Work、Codex 並未因此更換模型。[OpenAI 發布紀錄](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

未更改歷史底稿、Agent 頁、樣式、網址或部署設定。查核範圍僅限本批。
