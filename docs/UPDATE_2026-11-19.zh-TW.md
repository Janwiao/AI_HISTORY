# 2026-11-19｜AI 歷史資料增補

新增 Gemini 4 Neon（11/18 付費 API GA）、Hy4 flash（11/16 託管首發，另記後續開放權重）與 DaisyRose-27B（11/18 開放權重）；Genie 4 保留 10/27 研究預覽首發日，補 11/18 起向符合資格的 Google AI Ultra 訂戶分批開放。共 289 個模型／版本節點、34 品牌、9 張 Agent／工具卡。

| 項目 | 官方來源與口徑 |
|---|---|
| Gemini 4 Neon | 11/18 官方發表，Gemini API 付費層級一般可用（GA；gemini-4-neon），具 100 萬 token 上下文。Google 同日起在 Gemini app 與 Antigravity 等產品向指定方案分批推出，不等於免費層級可用。Neon 定位介於 Carbon 的高難度長程任務和 Hydrogen 的日常快速處理之間。 [來源 1](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)／[來源 2](https://aistudio.google.com/docs/changelog)／[來源 3](https://deepmind.google/models/model-cards/gemini-4-neon/) |
| Hy4 flash | 11/16 騰訊發布並於 TokenHub 提供，亦接入 WorkBuddy。支援文字及影像輸入，最高 100 萬 token 上下文。官方倉庫其後列出指令版、FP8 量化與預訓練基底的開放權重，採 Tencent Hy License；權重釋出與託管首發分開看，FP8 不是另一個模型節點。 [來源 1](https://www.tencent.com/tencent-launches-hy4-flash-to-power-high-speed-cost-efficient-ai-deployment-for-everyday-workflows/)／[來源 2](https://cloud.tencent.com/document/product/1823/130675)／[來源 3](https://github.com/Tencent-Hunyuan/Hy4-flash) |
| DaisyRose-27B | 11/18 RadixArk 發布 Qwen3.8-27B 的後訓練衍生模型；使用強化學習，未用監督微調或蒸餾，保留圖片理解與 256K token 上下文。BF16、FP8、NVFP4 權重以 Apache 2.0 釋出；三種精度不另算模型。 [來源 1](https://huggingface.co/blog/RadixArk/daisyrose-27b-pushing-the-frontier-of-post-trainin)／[來源 2](https://huggingface.co/RadixArk/DaisyRose-27B) |
| Genie 4 | Google DeepMind 世界模型，生成即時互動場景與原生音訊。10/27 公告向可信測試者推出研究預覽；11/18 起，Project Genie 向符合資格的 Google AI Ultra 訂戶分批開放，Google AI Pro 可加入等候名單。這是既有模型的存取擴大，不是 API 全面開放，也不是 Gemini 通用旗艦升代。 [來源 1](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/)／[來源 2](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/genie-4-now-available-project-genie/)／[來源 3](https://deepmind.google/models/model-cards/genie-4/) |

本批只查核上述項目，保留 208 筆底稿與原版面。Project Genie 代理功能未另計模型；Hy4 與 Hy4 flash 的權重狀態分開記錄。
