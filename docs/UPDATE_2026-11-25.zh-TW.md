# 2026-11-25｜AI 歷史資料增補

- **Hy-MT3（11/24）**：收錄 1.8B、7B、30B-A3B 三種規模，採騰訊官方開放權重日。原廠公告列 102 種語言、遊戲在地化與 OCR 後文字翻譯；這不是原生圖像輸入的證明。三款模型卡均列 Apache 2.0，量化格式與 TransRubric 評估工具不另計。[官方專案](https://github.com/Tencent-Hunyuan/Hy-MT3)／[1.8B](https://huggingface.co/tencent/Hy-MT3-1.8B)／[7B](https://huggingface.co/tencent/Hy-MT3-7B)／[30B-A3B](https://huggingface.co/tencent/Hy-MT3-30B-A3B)
- **SenseNova-U1.6-8B-MoT（11/24）**：採商湯正式公告日，不採權重倉庫建立日。原廠公告列影像生成、文字自修正與 ComfyUI；模型卡列影像編輯與 Apache 2.0 權重。只收一個模型，量化或加速 LoRA 不另計。[商湯公告](https://www.sensetime.com/cn/news/sensenova-u1-6-open-source-20261124-1152)／[模型卡](https://huggingface.co/sensenova/SenseNova-U1.6-8B-MoT)
- **ERNIE 5.5 Flash Preview**：保留 11/11 千帆 API 首發日。11/25 查核時，Baidu 的公開模型庫已列權重分片，模型卡明列 Apache 2.0，並列預設版、FP8、BF16。這是同一後訓練模型的後續存取事件，不另計模型；Flash Base 仍採不同授權。[API 首發](https://ernie.baidu.com/release/ernie-5-5-flash-preview/)／[權重模型卡](https://huggingface.co/baidu/ERNIE-5.5-Flash-Preview)
