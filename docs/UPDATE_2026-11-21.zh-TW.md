# 2026-11-21｜AI 歷史資料增補

本輪新增三筆、更新既有三筆。共 296 個模型／版本節點、37 個品牌、9 張 Agent／工具卡。

- **Aion-1.0-Instruct-2.3B（11/19）**：Microsoft 宣布正式提供可下載 MIT 權重，並成為符合條件的 Edge 裝置所用的內建小型語言模型。Prompt API 是網站來源試用；Decisions API 仍是開發者預覽。Windows 系統級推出不與 Edge 同步計為已上線；ONNX WebGPU 是同一模型格式。 [Microsoft 公告](https://blogs.windows.com/msedgedev/2026/11/19/hybrid-intelligence-on-the-web-introducing-aion-instruct-and-prompt-api-in-microsoft-edge/)／[模型卡](https://huggingface.co/microsoft/Aion-1.0-Instruct-2.3B)
- **Ideogram 4.6（11/19）**：提供代管的圖片生成與精準編輯 API，最高 4K，實際依模式而定。沒有將 Ideogram 4.0 的開放權重狀態套到 4.6。 [模型公告](https://ideogram.ai/models/4.6/)／[API 目錄](https://developer.ideogram.ai/v2/ideogram-api/models)
- **SenseNova-Loop-9B（11/17）**：官方正文與模型卡同列 11/17 正式發布。約 9B 參數，文字／圖像輸入、文字輸出，上下文上限 512K。模型卡標示 Apache 2.0，原始模型檔需接受 Hugging Face 資訊分享條件才可下載。11/18 是模型卡新增量化檔連結的日期，不另計節點。 [商湯公告](https://www.sensetime.com/en/news/sensenova-loop-9b-release-20261118-1435)／[模型卡](https://huggingface.co/sensenova/SenseNova-Loop-9B)
- **GPT-Live-1.1（API 11/19）**：只為既有主版補登 Live API 的開放日期與模型名 `gpt-live-1.1`，保留 10/15 的語音產品紀錄。不宣稱 Quip 同日進入 API。 [官方 API 更新紀錄](https://developers.openai.com/api/docs/changelog)

- **Genie 4（開發者 API 11/19）**：既有 10/27 研究預覽與 11/18 Project Genie 訂閱推出保留；新增 Gemini Interactions API 與 Google AI Studio 的開放紀錄。 [Google 開發者公告](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/)
- **Hy4（11/20 官方專案已列權重）**：維持 11/4 託管發布，不把 FP8 另計。官方專案也列出預訓練 Base，非聊天版。本輪只更新 Hy4 正式版的存取里程碑；專案採 Tencent Hy License 1.0，非原版 Apache 2.0。 [官方專案快照](https://github.com/Tencent-Hunyuan/Hy4/tree/6eb6613298923f528b6f991f1d81c319e3603829)／[授權檔](https://github.com/Tencent-Hunyuan/Hy4/blob/main/LICENSE)

歷史底稿、Agents & Tools、網址及頁面排版均未改；本輪只查核上述紀錄。
