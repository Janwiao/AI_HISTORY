# 2026-11-22｜AI 歷史資料增補

新增七筆、更新既有一筆。共 303 個模型／版本節點、37 個品牌、9 張 Agent／工具卡。

- **Inkling 2 Mini（11/20）**：同日開放 Tinker 推理／微調與 Apache 2.0 權重。26.4B 總參數、3.4B 啟用，三次循環對應每 token 約 5.4B 權重啟用；研究用 variable-loop 不另計。[原廠公告](https://thinkingmachines.ai/news/inkling-2-mini/)／[模型卡](https://huggingface.co/thinkingmachines/Inkling-2-Mini)
- **Inkling 2 Small（權重 11/12）**：保留 11/5 Tinker 首發，新增 11/12 Apache 2.0 權重開放里程碑。[原廠更新](https://thinkingmachines.ai/news/inkling-2-small/)／[模型卡](https://huggingface.co/thinkingmachines/Inkling-2-Small)
- **WeMM-Video（11/20）**：2B、4B、9B、35B-A3B 分列，日期取 BF16 權重所在的公開快照。可理解包含原聲的影片與其他模態，輸出文字；不當成影片生成模型，不將量化副本另計，也不假設有託管 API。[原廠模型清單](https://github.com/Tencent/WeMM-Video#model-zoo)
- **WeVisForensics（11/19）**：以五個角色 LoRA 適配器釋出為日期，並註明 11/16 研究報告。它是生成影片鑑識研究套件，不是五個獨立模型、完整基座權重或 Agent 產品。[技術報告](https://arxiv.org/abs/2611.21373)／[原廠釋出](https://huggingface.co/tencent/WeVisForensics/commit/9fa025a02dde4f7f7de8883fe17b6f251f39098e)
- **LongCat-Video-Avatar 1.6（11/13）**：公開權重與 v1 報告，MIT 模型卡；音訊驅動數位人影片生成與續作，INT8 不另計。不推論託管 API 已開放。[模型卡](https://huggingface.co/meituan-longcat/LongCat-Video-Avatar-1.6)／[技術報告](https://arxiv.org/abs/2611.18822)

未更新歷史底稿、Agent 頁、CSS、網址或部署設定。查核範圍僅限本批。
