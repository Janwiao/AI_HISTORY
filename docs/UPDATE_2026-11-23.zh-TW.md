# 2026-11-23｜AI 歷史資料增補

新增五筆，合計 308 個模型／版本節點、40 個品牌、9 張 Agent／工具卡。

- **Mind Lab Macaron-V1.1（9/22）**：原廠標示的 752B 由 744B GLM-5.3 基座與四組 2B LoRA 組成，不是啟用參數量；模型卡資料與權重公開，保留上游條款。11/16 與 11/20 的 Venti 系列記作阿里雲新加坡國際區上架，Venti Pro 增加圖片輸入，不斷言另有公開權重。[原廠公告](https://www.mindlab.im/updates/introducing-macaron-v1-1-and-mint-recursive)／[模型卡](https://huggingface.co/mindlab-research/Macaron-V1.1)／[阿里雲資料](https://www.alibabacloud.com/help/en/model-studio/newly-released-models)
- **Baseten bison-1／groundhog-1（11/20）**：以 Gemma 4 為底的決策分類模型，支援文字與圖片，回傳分類及評分等結構化結果；同日公告正式 API 與可下載權重。[原廠公告](https://www.baseten.co/blog/meet-bison-1-and-groundhog-1/)／[bison 模型卡](https://huggingface.co/baselabs/bison-1)／[groundhog 模型卡](https://huggingface.co/baselabs/groundhog-1)
- **Reson8 Rumble-2-Flash（11/3）及 Rumble-2（11/10）**：前者先開預錄音訊 API，11/18 再公告 Apache 2.0 權重，仍為同一模型；後者為不同的託管模型，支援即時轉寫，未確認開放權重。[Flash 首發](https://www.reson8.dev/blog/rumble-2-flash)／[Flash 權重公告](https://huggingface.co/blog/rumble-2-flash)／[Rumble-2 首發](https://www.reson8.dev/blog/rumble-2)

未更改歷史底稿、Agent 頁、樣式、網址或部署設定。查核範圍僅限本批。
